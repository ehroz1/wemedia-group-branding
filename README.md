# Бренд-кит WE media group

Сайт, где собраны логотипы и фирменные шрифты всех медиаплатформ группы:
WE media group, WE project (weproject.media, Creative Asia), THE TECH,
Город 24, OFFICE.

На сайте можно:

- скачать любой логотип в **SVG, PDF, EPS** (вектор) и **PNG, JPG** (растр);
- выбрать цвет — фирменный, белый или **любой свой**;
- выбрать фон — прозрачный, белый, чёрный или свой;
- выбрать размер картинки (512–8000 px);
- скачать всё по логотипу, по платформе или весь бренд-кит одним ZIP;
- скачать шрифты — семейством (ZIP) или каждое начертание отдельно;
- скопировать прямую ссылку на файл или на раздел платформы.

Внешний вид — как у picta.cc (светлая / тёмная тема, те же шрифты и кнопки).

## Как устроено

- `source/` — исходники в том виде, в каком их прислали (EPS, SVG, PNG, JPG,
  шрифты). **Сюда кладём новые логотипы и шрифты.**
- `tools/build.py` — собирает из исходников всё остальное: `assets/`,
  `downloads/`, `js/data.js`. Эти папки руками не правим.
- `index.html`, `css/styles.css`, `js/app.js` — сама страница, без сборки и
  фреймворков.

Логотипы OFFICE, THE TECH (обе версии) и Creative Asia пришли только
картинками, их векторные версии получены трассировкой (potrace). Если найдутся
оригиналы в AI/EPS/SVG — положите их в `source/logos/` и пересоберите.

## Пересборка

Нужны: Python 3 с `fonttools` и `brotli`, `ghostscript`, `inkscape`,
`potrace`, `imagemagick`, `librsvg2-bin` (rsvg-convert), `svgo` (npm).

```sh
python3 tools/build.py
```
